morluto/rea — 现象级增长进入「常态吸星」阶段
为什么推荐：月增 42.5 万仍是本月独一档；关键新信号是离开周榜后仍日增约 2.8K——流量脉冲已转化为默认推荐式增长，这是从「热点」变「基础设施」的分水岭信号。

为什么推荐：周增 +15,379 连续多周断层第一，478 贡献者为三榜社区健康度之首，「不卖东西」的开源宣言 + 平台期稳定增长，是 agent 时代「外设层」最早跑出来的枢纽。

NVIDIA 双子星：auto-ontology + NVKE — 企业 agent 地基的两块开源基石
