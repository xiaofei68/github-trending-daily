1Agent 编排进入「平台化竞赛」，大厂集体入场

3上下文工程与记忆层独立成层

4逆向工程复兴周：agent × 安全是被低估的方向

周榜「逆向三杰」：rea（+201k）、AnyPS5（+12.4k）、ghidra（+7.2k）；月榜还有 cloudflare security-audit-skill（24h +1,392 暗流）。判断：agent 大幅降低逆向门槛 + 全球安全人才缺口，「用 agent 做安全」同时具备就业价值（红队 / 审计）与创业价值（合规审计服务）。

5本地化开源替代不可逆，「local-first」成为默认卖点

VoiceStudio（本地 ElevenLabs，月增全场第一）、freellmapi（34 家免费 LLM 聚合）、ComfyUI（常青）、ai-job-search（数据不出本机）、AnyPS5（网页转换器文件不离开设备）。判断：隐私 + 成本 + 可控三力驱动，「本地优先 / 数据不出设备」正从卖点变成产品默认项——做产品时把它写进架构，而不是事后补。
