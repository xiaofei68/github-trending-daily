🔮 GitHub 技术趋势 3～5 个
  1. ① Agent Skills 开放生态爆发
    OpenAI（skills→plugins）、Anthropic（claude-plugins-community）、Cursor（plugins）三家厂商 + agentskills.io 开放标准，叠加 obra/superpowers、mattpocock/skills、archify、diagram-design、ponytail 等社区项目。一个跨厂商可移植的"Agent 技能包"格式正在形成，是当前 GitHub 最显眼的集群。
  2. ② Agent 上下文/记忆成独立基础设施层
    context-mode（上下文压缩）、semantica（图原生上下文+知识图谱）、OpenViking（Agent 上下文数据库）、ai-memory（跨 Agent 长期记忆）、hermes-agent（记忆环）。"上下文管理"正从 prompt 技巧升级为独立中间件层。
  3. ③ Agent 浏览器自动化 + 反检测
    chrome-devtools-mcp（DevTools 即 MCP）、browser-use（113k，浏览器即 Agent）、camofox-browser（隐身反检测）。浏览器作为 Agent 执行面 + MCP 标准化双向成熟。
  4. ④ 大厂核心系统开源
    x-algorithm（X 推荐流）、modular/modular（Mojo 语言 + MAX 平台开源）。大厂愿意把"看家算法/平台"拿出来，透明度与生态拉拢并重。
  5. ⑤ 端侧微型模型与本地训练
    needle（14MB 工具调用模型）、unsloth（本地训练/运行 LLM）。端侧 + 离线 + 隐私路线在小模型侧持续突破。
